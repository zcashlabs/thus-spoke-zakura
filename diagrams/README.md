# Diagrams

Every figure in `book/images/*.svg` is generated by `build.py`. Edit the spec
there, never the SVG.

```sh
python3 diagrams/build.py
```

Layout is hand-placed rather than solved by a layout engine: the coordinates in
`build.py` are chosen so figures share a grid, gaps stay even, and no arrow
routes through a box. The build prints a warning when a label looks too wide
for the card it sits in.

Two rules keep the figures readable:

- **Labels are a few words.** The sentences belong in the numbered list under
  the figure in the chapter, not inside the drawing.
- **The accent colour means one thing per figure** — the path that chapter is
  about. Everything else is neutral.

Each figure carries its palette as CSS custom properties plus a
`prefers-color-scheme: dark` override, so the SVG follows the reader's theme.
The `aria-label` in each figure is the source of truth for its alt text in the
markdown; re-run `build.py` and re-sync if you change one.
